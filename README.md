# fragkakis/homebrew-tap

Homebrew casks for my apps.

```sh
brew install --cask fragkakis/tap/prty-time
```

| Cask | App |
|---|---|
| `prty-time` | [PRty Time](https://github.com/fragkakis/prty-time): menu-bar app for the GitHub pull requests waiting on you |

The cask is updated automatically when PRty Time publishes a release.
